# Well Depth Map

This folder stores observed well-depth data and the GIS layers used to map groundwater-level or well-depth patterns in the Chikkaballapur study area.

## Inputs

- `Well Depth Data.csv`: well-depth observations.
- `Monthly Manual Monitoring - MMMW.csv`: monthly manual monitoring observations.
- `DEM_250m.asc`: 250 m elevation input.
- `depth map complete`: completed well-depth vector map and shapefile sidecars.

## Outputs

The QGIS project, map image, and processed well-depth vector layer are visualization and mapping outputs. The folder does not contain a Python processing script.
